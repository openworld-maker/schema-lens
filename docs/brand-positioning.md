# SolrGuard Brand Positioning

## Old positioning

- Schema-Lens
- Solr schema/config impact simulator

## New positioning

- SolrGuard
- Search Change Governance for Apache Solr

## Tagline

SolrGuard is a search change governance toolkit for Apache Solr.

## Extended positioning

SolrGuard helps teams detect compatibility issues, simulate change impact, enforce policies, produce auditable approvals, and operationalize safer rollout decisions for Apache Solr.

## Core personas

- Solr relevance engineers
- platform engineering teams
- SRE and release governance teams
- Apache Solr operators and ecosystem contributors

## Enterprise value proposition

- deterministic compatibility and fallback visibility
- policy-driven release gates and approvals/exceptions
- secure, privacy-aware artifact handling
- rollout planning and post-cutover verification
- observability-friendly governance workflows

## Messaging guidance for contributors

Prefer:

- "search change governance toolkit"
- "policy-driven change safety"
- "rollout governance for Solr"

Avoid as primary framing:

- "just a simulator"
- "toy/experimental utility"

## Ecosystem framing

SolrGuard is designed for production change governance in Apache Solr environments, with local-first operation and CI/CD-friendly artifacts.
