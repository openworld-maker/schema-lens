# Approvals and Exceptions

Governance metadata includes approval and exception records for promotion decisions.

## Approval metadata

- approver/requestor identity
- rationale
- ticket/reference
- target promotion state

## Exception metadata

- exception id
- reason + owner
- created/expiry timestamps
- bypassed policy scope
