# Multi-tenant and Segment-aware Reporting

SolrGuard can compute global and segment breakdowns for impact/risk.

## Segment dimensions

- tenant
- region
- locale
- catalog/business labels

## Outputs

- `segments.json`
- `compare.json.segments`
- `report.json.segments`
