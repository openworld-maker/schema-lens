# Privacy and Retention Controls

SolrGuard provides configurable masking and retention controls for enterprise query/doc artifacts.

## Controls

- PII masking profiles
- hashed doc id mode
- export-safe summary behavior
- no raw sensitive persistence mode
- retention cleanup policy
